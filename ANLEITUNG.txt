VERSIONEN / SPÄTERE UPDATES
worksmanager-release.json enthält einen numerischen Build-Wert. Wenn ein neues Release veröffentlicht wird, neue Haupt-/Zusatzdateien bereitstellen, den numerischen Build in der nächsten Clientversion aktualisieren und zuletzt den Build in der Versionsdatei erhöhen. Die neue Update-Anzeige erkennt eine höhere Build-Zahl über einen Online-Abruf.
Die App kann nicht automatisch eigenständig Dateien auf GitHub ändern. Browser- und iOS-Speicher können trotz Service Worker gelöscht werden, daher externe Backups aufbewahren.

Dies ist ein vorbereitetes Update, nicht auf GitHub veröffentlicht. Haupt-App v1.8.4 und verschlüsselte IndexedDB bleiben unverändert.
